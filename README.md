# Too Many Ideas — phone generator

A tiny static web app. No database or server-side code is required.

## Put it online using GitHub Pages
1. Create a GitHub repository, e.g. `too-many-ideas-generator`.
2. Upload `index.html`, `data.js`, `manifest.webmanifest`, and `sw.js` to the repository root.
3. In GitHub: Settings → Pages → Build and deployment → Deploy from a branch.
4. Choose `main` and `/ (root)`, then Save.
5. Open the HTTPS URL GitHub gives you on your phone.
6. On iPhone Safari: Share → Add to Home Screen.

## Generator logic
- choose a hidden A parent
- choose one B child belonging to that parent
- choose one independent C academic concept
- choose one independent D real-world item/activity
- display only B + C + D
